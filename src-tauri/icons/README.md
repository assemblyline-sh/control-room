# Icons

Source: `source.svg` — a 1024×1024 wrapper around the brand mark in `public/logo.svg`, with the `#0b0e14` app background and white mark scaled to fit with iOS-style corner radius.

The platform variants (32×32, 128×128, `@2x`, `icon.icns`, `icon.ico`, plus iOS / Android / Windows Store assets) were generated by running:

```bash
npx @tauri-apps/cli@2 icon src-tauri/icons/source.svg
```

Regenerate after editing `source.svg`. The `tauri build` command reads only the five entries listed in `../tauri.conf.json`; the other generated files (`ios/`, `android/`, `Square*.png`, `StoreLogo.png`) are kept for future mobile / Microsoft Store work.
